# Lab0: Basic Wireshark Operation and Capture

## 1. Wireshark installation guide (Windows 11)

First, go to the Wireshark website in the downloads section: https://www.wireshark.org/download.html

Then, click the Windows Installer download link for your processor's architecture (x64 or ARM).

![sc1](/screenshots/lab0/sc1.png)

After the download is complete, open the installer and click 'Next'. Make sure you grant the installer all the permissions it asks for.

![sc2](/screenshots/lab0/sc2.png)

After reading and accepting the terms and conditions, keep clicking 'Next' until you see the 'Install' button. You can optionally change the download path, start menu icon and installed plugins and add-ons, but this is optionnal as you can just leave all of the default options.

![sc3](/screenshots/lab0/sc3.png)

When the installation is complete, simply click 'Finish'. You have now successfully installed Wireshark on your computer.

DNS (Domain Name System) is the system used to translate human-readable web domains into machine-readable IP addresses.

### 3.1 What is the IP address and port of the DNS server

IP address is 140.118.31.99, port is 53 (from Dst).

### 3.2 What is the domain name in the query?

The domain name is badssl.com

### 3.3 Protocols used by the DNS packet

![sc10](/screenshots/lab0/sc10.png)

The 'Ethernet II' line represents Layer 2, which is the link layer.
The 'Internet Protocol Version 4' (IPv4) line represents Layer 3, which is the network layer.
The 'Transmission Control Protocol' (TCP) line represents Layer 4, which is the transport layer.
The 'Domain Name System' (DNS) line represents Layer 5, which is the application layer.
